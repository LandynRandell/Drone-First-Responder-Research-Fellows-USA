# Drone-First-Responder-Research-Fellows-USA
A drone and ground rover system linked with a ground control station (GCS), built for first-responder aid and search-and-rescue use in mixed terrain, with mentors from the University of South Alabama and students like myself at the Alabama School of Math and Science, we grew in our understanding of systems as well as our knowledge of code and design. 

##What this does
-Autonomous drone flight using ArduCopter and GPS waypoints
- Ground rover with object detection for mixed terrain

##Tools used
Python | pymavlink | Arducopter | MAVlink | SEEED Odyssey | 915Mhz RF telemetry |
